# 云桥 SSH

在浏览器里连接和管理服务器的网页版 SSH 客户端，思路参考 FinalShell、Termius、WindTerm 这类工具：左边是主机列表，中间是终端，右边是文件管理、监控和快捷命令。

## 功能

- **主机管理**：保存主机（密码或私钥登录），支持分组、搜索、备注、复制主机、复制 `ssh` 命令；也可以直接输入 `root@1.2.3.4:22` 快速连接。
- **多标签终端**：基于 xterm.js，256 色，自适应窗口大小，终端内查找，Ctrl+Shift+C / V 复制粘贴，右键复制/粘贴，字号调节，断线一键重连。
- **SFTP 文件管理**：浏览目录、上传（含拖拽上传，带进度）、下载、目录打包成 tar.gz 下载、在线编辑文本文件（Ctrl+S 保存）、新建、重命名、修改权限、删除，以及“在终端中进入此目录”。
- **实时监控**（Linux）：CPU、内存、交换分区、网络速率、磁盘占用、进程列表（可结束进程），每 3 秒刷新，附带走势小图。
- **快捷命令**：常用命令一键执行；命令输入框支持历史记录，可以同时发送到所有已连接的会话。
- **安全**：
  - 首次打开时设置访问密码，登录态为签名 Cookie（HttpOnly + SameSite=Strict），连续输错 5 次锁定 60 秒。
  - 服务器密码、私钥、私钥口令用 AES-256-GCM 加密后保存在 `data/` 目录，接口不会把它们返回给浏览器。
  - 记录服务器指纹，指纹变化时拒绝连接并提示（防中间人），用户确认后才信任新指纹。
  - 写操作需要自定义请求头，WebSocket 校验来源，防止跨站请求。
- 浅色 / 深色主题，窄屏可用。

## 运行

需要 Node.js 18 或更高版本。

```powershell
npm install
npm start
```

然后在浏览器打开 <http://127.0.0.1:8822>。Windows 下也可以直接双击 `启动.bat`。

### 配置（环境变量）

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `8822` | 监听端口 |
| `HOST` | `127.0.0.1` | 监听地址。默认只允许本机访问；需要从其他设备访问时设为 `0.0.0.0`，并建议放在 HTTPS 反向代理之后 |
| `YQ_DATA_DIR` | `./data` | 数据目录（主机、快捷命令、访问密码、加密密钥） |
| `TRUST_PROXY` | 不启用 | 在反向代理之后运行时设为 `1`，以便获取真实 IP 和识别 HTTPS |

> `data/secret.key` 是加密密钥，丢失后已保存的密码和私钥将无法解密；迁移时请连同整个 `data/` 目录一起复制。忘记访问密码时，删除 `data/config.json` 中的 `passwordHash` 一行后重启即可重新设置。

## 项目结构

```
server/
  index.js   服务入口：静态页面、REST 接口、终端 WebSocket
  ssh.js     SSH 连接与会话管理（ssh2）
  sftp.js    SFTP 文件接口
  stats.js   服务器监控（读取 /proc）
  store.js   本地数据存储与加密
  auth.js    访问密码与登录态
public/
  index.html
  css/tokens.css  设计变量（苹果式简约设计语言）
  css/app.css     界面样式
  js/app.js       入口：登录、布局、标签页、主机列表、主页、设置
  js/session.js   终端会话（xterm.js）
  js/files.js     文件管理面板
  js/monitor.js   监控面板
  js/commands.js  快捷命令面板
  js/hosts.js     主机表单、快速连接
  js/ui.js        对话框、菜单、提示等通用组件
```
